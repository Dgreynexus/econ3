# EconoPH 2026 – Socio-Economic Factors PWA Learning Repository

An interactive, bilingual (English / Filipino), offline-capable Progressive Web Application (PWA) built around the **Content Matrix: Socio-Economic Factors and Their Effects (2026 Philippine Economic Context)**.

## Included Curriculum Modules
1. **Inflation (*Implasyon*)** – Oct 2026 Headline Inflation at **7.8%** (up from 2.0% in Jan 2026); Rice at **20.7%**, Transport at **20.1%**.
2. **Unemployment (*Kawalan ng Trabaho*)** – Sept 2026 Unemployment at **5.4%** (2.86M jobless Filipinos, up from 3.8% in Sept 2025); Underemployment ~**11%**.
3. **Income (*Kita*)** – Q3 2026 GDP growth at **2.1%** (down from 2.4% in Q2 2026; Jan–Sept 2026 average: **2.5%**).
4. **Technology (*Teknolohiya*)** – E-wallets (GCash/Maya), QRPh, social commerce, and delivery platforms bridging slow walk-in traffic.
5. **Consumer Behavior (*Gawi ng Mamimili*)** – Trading down to value brands, buying *tingi* (micro-portions), and online price comparison.

## Repository Structure
- `index.html` – Complete responsive application (Factor Explorer, Full Matrix Table, Sari-Sari & MSME Impact Simulator, Flashcards & Quiz).
- `manifest.json` – W3C Web App Manifest for installing on Android, iOS, and Desktop.
- `sw.js` – Offline-first Cache API Service Worker.
- `README.md` – Classroom deployment & offline usage guide.

## How to Run & Install as a PWA
1. Serve this folder over HTTPS or `localhost` (e.g., `npx serve .` or GitHub Pages).
2. Open in Chrome, Edge, or Safari and click **"Install App"** or **"Add to Home Screen"** for full offline classroom access.
